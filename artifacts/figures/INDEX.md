# Figure index

Every figure in this project, with the caption it carries, the script that draws it and the files that script reads. Generated by `python -m app.research.figure_index` from `manifest.jsonl`, which `app.research.plotstyle.save` appends to at render time — so a caption here is the figure's own, not a transcription. Regenerate the whole pack with `make figures`.

109 figures recorded. Each is written as a 300 DPI PNG and a vector PDF of the same name.
